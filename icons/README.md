# icons directory

This repository uses icons referenced from manifest.json at `icons/icon-192.png` and `icons/icon-512.png`.

Please add your PNG icons in that folder. Recommended sizes:

- icons/icon-192.png — 192×192 PNG
- icons/icon-512.png — 512×512 PNG

You can generate multi-size icons (including Apple touch icons) using https://realfavicongenerator.net/ or a design tool. Once added, the PWA installability will detect them automatically.
