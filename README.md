Getting started
---------------
1. Clone the repository:

   git clone https://github.com/harshvardhan9084/strip.git

2. Create a feature branch for your work (replace `feature-name`):

   git checkout -b feature/feature-name

3. Add your game code. A suggested minimal layout:

   - src/           — JavaScript source files (game logic)
   - public/        — static assets (HTML, CSS, images)
   - README.md      — this file

4. If your game is purely static (HTML + JS + CSS), you can open public/index.html in a browser, or serve the directory with a simple static server, for example:

   npx http-server public

   or

   python -m http.server --directory public 8000
